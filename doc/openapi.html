API definition for a separately deployed experimental pkimetal fork with MTC draft-05 and CQRP v0.2.0 linting. It does not describe capabilities of the upstream hosted services or container images.

cert

Operations related to X.509 certificates

Lint a Certificate

Lints a complete X.509 Certificate or Precertificate. Experimental MTC draft-05 and CQRP v0.2.0 linting is selected with an explicit MTC profile; autodetection never selects CQRP.

query Parameters
profile
string
Default: "autodetect"

Profile name. MTC values are mtc_ca, mtc_subscriber, cqrp_mtc_ca, and cqrp_mtc_subscriber. Omit or use autodetect for structural detection; CQRP profiles must be explicit. Other legacy profile names remain supported and are intentionally not constrained by an enum.

format
string (ResponseFormat)
Default: "json"
Enum: "json" "html" "text"

Response format; overrides Accept when present.

severity
string (FindingSeverity)
Enum: "meta" "debug" "info" "notice" "warning" "error" "bug" "fatal"

Minimum included severity. Use meta to include status metadata.

Request Body schema:
required

A PEM/Base64 form value or a raw complete DER Certificate. For raw DER, send profile, format, and severity as query parameters.

Any of
format
string (ResponseFormat)
Default: "json"
Enum: "json" "html" "text"

The response format

profile
string
Default: "autodetect"

Profile name. The four MTC values are mtc_ca, mtc_subscriber, cqrp_mtc_ca, and cqrp_mtc_subscriber. Legacy names remain supported, so this property intentionally has no enum.

severity
string (FindingSeverity)
Enum: "meta" "debug" "info" "notice" "warning" "error" "bug" "fatal"

The severity of a linter finding

b64input
required
string

The caller's Base64 or PEM-encoded complete Certificate.

b64cert
string

Endpoint-specific alias for b64input; takes precedence when both are present.

Responses

Experimental local fork deployment

http://localhost:8080/lintcert
